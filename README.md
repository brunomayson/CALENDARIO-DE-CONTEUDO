# Laboratório dos Números (HTML Standalone)

Este repositório inclui uma versão em HTML do "Laboratório dos Números". Você pode abri-la diretamente no navegador ou empacotá-la em um aplicativo usando ferramentas como Capacitor ou Cordova.

## Arquivo principal

- [`laboratorio-numeros.html`](laboratorio-numeros.html) — página completa com estilo e lógica em JavaScript.

## Como abrir no navegador

1. Faça o download do arquivo `laboratorio-numeros.html`.
2. Clique duas vezes no arquivo ou abra-o com o navegador de sua preferência (Chrome, Edge, Firefox etc.).
3. A experiência completa será carregada sem depender de servidor.

## Como baixar apenas o arquivo HTML

Se você quiser baixar somente o arquivo para testes:

```bash
curl -O https://raw.githubusercontent.com/<seu-usuario>/<seu-repositorio>/main/laboratorio-numeros.html
```

Substitua `<seu-usuario>` e `<seu-repositorio>` pelos valores corretos após publicar o repositório.

## Convertendo para aplicativo (opcional)

1. Crie um novo projeto com Capacitor ou Cordova.
2. Copie o arquivo `laboratorio-numeros.html` para a pasta `www/` do projeto.
3. Defina-o como página inicial (por exemplo, `index.html`).
4. Gere o build para Android/iOS seguindo a documentação da ferramenta escolhida.

Isso permitirá testar a experiência como um aplicativo nativo.
